# Web Word 多标签工具栏技术规格说明书 (Word Ribbon Specification)

## 1. 概述与背景

为全面对齐 WPS 与桌面级专业文字处理软件的交互体验，Web 端文字文档编辑器由原有的单一工具栏升级为工业级 **Ribbon 多标签页工具栏体系**。
本规范定义了「开始」、「插入」、「页面」、「审阅」、「视图」五大功能 Tab 及其二级子功能、排除项设计边界，并为移动端及桌面端提供统一交互指南。

**设计边界声明**：
- 严格剔除多账号、AI 相关功能（如 WPS AI 助手、AI 目录生成、AI 校对、全文翻译、协作者颜色显示、多用户权限加密等）。
- 完整补齐通用文字处理、版式排版、对象插入、页面渲染与视图控制功能。

| | 重做 (Redo) | `editor.chain().redo().run()` | 已实装 |
| | 格式刷 (Format Painter) | 暂存光标或选区 marks 与 styles，拖选目标应用并重置 | 已实装 |
| | 清除格式 (Clear Format) | `editor.chain().unsetAllMarks().clearNodes().run()` | 已实装 |

| | 字号选择 (`WordSizeSelector`) | 初号~八号、小初~小六、8~72pt | 已实装 (下拉选择) |
| | 字号步进 (`A⁺` / `A⁻`) | 按中文字号阶梯递增/递减当前选区字号 | 已实装 |
| **字形与色彩** | 粗体 / 斜体 / 下划线 / 删除线 | `toggleBold`, `toggleItalic`, `toggleUnderline`, `toggleStrike` | 已实装 |
| | 上标 (Superscript) / 下标 (Subscript) | `toggleSuperscript`, `toggleSubscript` | 已实装 |
| | 文本高亮色 (Highlight) | 记号笔多色矩阵拾取器 (`WordColorPickerDropdown type="highlight"`) | 已实装 |
| | 字体颜色 (Font Color) | 10×6 主题渐变色矩阵 + 标准色 + 自定义拾色器 | 已实装 |
| **段落与列表** | 段落样式 | 正文、标题 1 (H1)、标题 2 (H2)、标题 3 (H3)、引用块、代码块 | 已实装 (下拉选择) |

| 模块 | 功能项 | 动作与接口定义 | Web 状态 |
| :--- | :--- | :--- | :--- |
| **分页与页面** | 分页符 (Page Break) | 插入水平分页虚线隔离带 | 已实装 |
| | 空白页 (Blank Page) | 插入新页面容器与换行段落 | 已实装 |
| **表格系统** | 网格表格拾取器 (`WordTableGridPicker`) | 悬浮拾取最大 8×8 网格，点击一键生成表格 | 已实装 |
| | 表格操作工具组 | 光标处于表格内时，在上方/下方插入行、左侧/右侧插入列、删除行/列/整表 | 已实装 |
| **媒体与对象** | 图片插入 (Image) | 支持本地相册/文件选择 (DataURL) 或网络图片 | 已实装 |
| | 水平分割线 (Horizontal Rule) | 插入标准段落分隔线 | 已实装 |
| | 提示卡片 (Callout Box) | 插入带重点强调样式的说明卡片 | 已实装 |
| **符号与链接** | 特殊符号库 (`WordSymbolModal`) | 货币 (¥ $ € £)、数学 (± × ÷ ≤ ≥ ∑ √ π)、标点序号 (— 「」 ① ②)、特殊符号 (© ® ★ ✓) | 已实装 |
| | 超链接 (Hyperlink) | 弹出输入链接地址与显示文本，支持编辑与一键取消 | 已实装 |
| | 当前日期与时间 | 一键插入系统格式化日期时间 (`YYYY-MM-DD HH:mm`) | 已实装 |

### 2.3 【页面】Tab (`page`)
专注纸张规格、版面布局、底色与水印设置。

| 功能项 | 调节范围 | 呈现方式 |
| :--- | :--- | :--- |
| **页边距 (Margins)** | 普通 (68px 74px)、窄 (32px 36px)、适中 (50px 50px)、宽 (90px 100px) | 动态响应 `.word-page` padding |
| **纸张方向 (Orientation)** | 纵向 (Portrait) / 横向 (Landscape) | 动态调整画板宽度与高度比例 |
| **纸张大小 (Paper Size)** | A4 (794px)、A3 (1123px)、Letter (816px) | 切换国际标准纸张版心尺寸 |
| **分栏 (Columns)** | 单栏 (1)、两栏 (2)、三栏 (3) | CSS `column-count` 与 `column-gap` 实时多栏排版 |
| **页面底色 (Background)** | 纯白、护眼绿 (`#c7edcc`)、复古羊皮纸 (`#faf6ed`)、冷灰 (`#f4f5f7`) | 调整页面纸张背景色 |
| **页面水印 (Watermark)** | 无水印、草稿 (DRAFT)、绝密 (TOP SECRET)、机密 (CONFIDENTIAL)、内部资料 | 半透明 45° 旋转文字水印层覆盖 |
| **插入目录 (TOC)** | 一键生成文档目录 | 实时提取文档 H1~H3 层级生成缩进目录块并支持点击 |

### 2.4 【审阅】Tab (`review`)
专注字数统计、查找替换与文档保护。

| 功能项 | 说明与交互细节 | Web 状态 |
| :--- | :--- | :--- |
| **详细字数统计 (`WordCountModal`)** | 模态弹窗展示：中文字符数、单词数、字符数 (计空格/不计空格)、段落数 | 已实装 |
| **查找与替换 (`WordFindReplaceBar`)** | 悬浮搜索栏：关键字查找定位、高亮匹配数、上一个/下一个、单个替换/全部替换，支持 `Ctrl+F` 快捷键调起 | 已实装 |
| **只读保护状态** | 切换编辑器 `editable` 状态，保护文档免受误触改动，底栏实时显示状态 | 已实装 |

| :--- | :--- | :--- |
| **文档大纲 (`WordOutlineDrawer`)** | 左侧抽屉展示标题树，点击标题平滑滚动并对齐光标 | 已实装 |
| **标尺开关 (Ruler)** | 切换顶部标尺刻度条（`page-ruler`）的显示与隐藏 | 已实装 |
| **护眼模式 (Eye Care)** | 画布底色整体切换为浅绿护眼色，降低视觉疲劳 | 已实装 |
| **视图缩放 (Zoom)** | 75%、90%、100%、125%、150%，CSS `scale` 缩放画板 | 已实装 |
| **专注模式 (Zen Mode)** | 全屏沉浸式隐藏外部导航与工具栏，专注于写作 | 已实装 |
